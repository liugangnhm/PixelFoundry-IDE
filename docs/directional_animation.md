# 多方向角色动画

## 使用

在 **Solo → 输入参数 → 动画方向** 中选择：

- **单方向（当前视角）**：原有流程，默认选项。
- **四方向**：正面、左侧、背面、右侧。
- **八方向**：四方向加左前、左后、右后、右前。

输入同一个角色描述和动作，设置帧数、画布、处理与导出选项，然后开始生成。
多方向仍然使用设置中的默认文本、图像和视频 API，包括 Agnes AI。
每个方向分别调用图像与视频生成接口，耗时及 API 用量随方向数增加；默认顺序执行。

推荐上传已经确定外观的角色参考图：多方向模式会直接将它用作母图
（可进行原有的背景归一化），不先让模型重画角色。如果没有参考图，则先生成一次母图。
完成后，右侧预览上方的方向下拉框可切换不同动画；「同步到 IDE」发送当前选中方向，
「打开输出目录」打开整个方向批次。

本功能接入 Solo 的图转视频流程；精灵图模式目前仍为单个动作、单个视角。

## 方向约定

方向描述以屏幕为准，保持参考图的摄像机高度，不自动改成俯视或等距透视。

| ID | 视图 | 屏幕朝向 |
| --- | --- | --- |
| `south` | 正面，朝向观看者 | 下 |
| `southwest` | 左前 3/4 | 左下 |
| `west` | 左侧面 | 左 |
| `northwest` | 左后 3/4 | 左上 |
| `north` | 背面，背对观看者 | 上 |
| `northeast` | 右后 3/4 | 右上 |
| `east` | 右侧面 | 右 |
| `southeast` | 右前 3/4 | 右下 |

## 一致性措施与边界

1. 所有方向都引用**同一张母图**，不会用“上一方向的生成图”连续转向。
2. 正向提示词约束脸、体型、服装、装备、配色、像素风格及构图；明确要求真实视角，
   不以左右翻转替代生成，避免非对称装备换到身体另一侧。
3. 每个方向的静态图直接作为动画首帧；动画提示词要求维持该朝向、原地动作和固定镜头。
4. 启用像素化时，从母图提取共享调色板，各方向共用；统一用户设置的输出画布。
   关闭像素化时也会以最近邻统一输出画布，但不强制母图调色板。
5. 原有循环闭合、去背景及各格式导出仍然生效。

这些措施提供输入和后处理约束，**不等于角色身份的模型级锁定**。
背面及遮挡装备仍由模型推断；提示词中的脚底线、比例、朝向与非对称细节没有自动视觉验收，
需检查结果。Perfect Pixel 网格仍按各方向的动画分别检测，未实现跨方向统一原生网格。
目前也未加入角色档案、多动作批量生成、方向自动评分或错误方向自动重试。

## 输出

```text
run_.../
  animations.json                 # 批次状态、方向、相对路径、帧数、fps、共享配色
  artifacts/character_master.png   # 此次共用的角色母图
  directions/
    south/
      artifacts/view.png           # 该方向的静态参考图
      artifacts/first_frame.png
      frames/                     # 最终帧序列
      export/                     # 勾选的 GIF / PNG / APNG / 精灵图及项目文件
    west/ ...
    north/ ...
    east/ ...
  export/directional_sprite_sheet.png  # 勾选精灵图导出时额外生成
```

合并精灵图为**每方向一行、动作帧从左到右**；行顺序由 `animations.json.direction_order`
记录，各方向包含 `row`、`frame_count`、`fps` 等数据。列数为各方向最大帧数；不足部分透明填充，
不会重复帧伪造动作。批次文件不依赖绝对路径。

已完成方向在每个方向结束后写入清单。后续失败或取消时保留文件，清单状态分别为
`failed` / `cancelled`；目前没有自动续跑功能。取消在步骤边界检查，正在进行的网络调用
沿用原有行为，需等待返回或超时。

## 验证

```powershell
.venv/Scripts/python.exe -m pytest tests/test_directional_workflow.py -v
.venv/Scripts/python.exe scripts/smoke_directions.py --mock --directions 8
```

真实 Agnes 测试：在当前进程环境中设置 `AGNES_API_KEY`，执行：

```powershell
.venv/Scripts/python.exe scripts/smoke_directions.py --directions 4 --reference path/to/character.png
```

脚本会真实生成每个方向的图像与视频并消耗相应配额；输出位于 Git 忽略的
`.tmp/directional-smoke/`。不要把真实 Key 写进文件或提交记录。
